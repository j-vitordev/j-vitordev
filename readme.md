### 📦 Order Notification System (Backend + Docker)

Backend application built with **Java 17 + Spring Boot**, following REST principles and integrated with **MySQL**.  
The project is fully **Dockerized using Docker Compose** and simulates a real order lifecycle.

**Main features:**
- CRUD for orders and customers  
- Order status management  
- Soft delete strategy  
- REST API design  
- Dockerized environment (backend + database)
